# 玩具厂计件计数与工资结算 · 操作手册

> 适用版本：v1.0.0（Android 单机版）
> 使用者：车间统计员 / 老板娘 / 厂长，一台手机一个人用
> 一句话：**装到手机上就能用，不联网也能记账、算钱、发工资条。**

---

## 一、安装

1. 把 `app-release.apk` 传到手机（微信文件传输助手、数据线、U 盘都行）。
2. 点开文件安装。若提示「未知来源应用」，在弹窗里选「允许」或到
   `设置 → 应用 → 特殊权限 → 安装未知应用` 里放行一次。
3. 桌面出现「玩具厂计件」图标，点开即可用。

> 换手机、恢复出厂、误删重装之前，**务必先做一次备份**（见第六节）。

---

## 二、第一次使用（约 10 分钟）

按「设置 → 档案管理」的顺序建好两本底档，之后录计数就只用点选了。

### 1. 建工人档案

`设置 → 工人档案 → 右上角「新增」`

| 字段 | 说明 |
| --- | --- |
| 姓名 | 允许重名，靠编号区分（张三 W001 / 张三 W002） |
| 编号 | 自动生成 W001、W002…，可改成厂里现有工号，**建好后不能改** |
| 拼音首字母 | 自动生成，用来快速搜人；多音姓氏（单/曾/解/查/仇/区…）可手动改 |

### 2. 建玩具与工序

`设置 → 玩具与工序 → 右上角「新增」`

| 字段 | 说明 |
| --- | --- |
| 玩具名 | 例如「小熊」 |
| 工序 | **点一下从列表里选**，不用手打；默认「整件」 |
| 单价 | 单位「元」，**最多 4 位小数**，如 0.035 |

**工序怎么选：**

- 点「工序」会弹出选择列表，预置了 15 个常用工序（整件 / 裁剪 / 缝头 / 缝纫 / 充棉 / 封口 / 手工缝合 / 装配 / 装眼 / 绣花 / 印花 / 剪线 / 整烫 / 包装 / 质检）；
- 列表里没有合适的，点顶部 **「新增工序」**，打字保存后**立刻选中**，而且以后都留在列表里，不用再打一遍；
- 自定义工序右侧有删除按钮。**已经被玩具档案用着的工序删不掉**（会提示），预置工序也不能删——避免历史流水里的工序名突然没有来源；
- 同一玩具不同工序请**分开建**（小熊·整件 / 小熊·充棉）。

> 单价改过之后，**历史流水不会变**：系统在记账时就把当时的单价存下来了。
> 同一工序中途调价，结算时会自动拆成两行分别显示。

## 三、每天记账（最常用）

打开「计数」页，从上到下四步：

1. **核对日期和时间**：默认今天、当前时刻。补记昨天下午的活，点「改日期」选昨天，再点「改时间」选几点做完的。
2. **选工人**：点「工人」卡片，可按姓名、拼音首字母（如 `zs`）、编号搜索。
3. **选玩具 / 工序**：点「玩具 / 工序」卡片，单价会自动带出来。
4. **确定是不是加班**：卡片里的「正常班 / 加班」开关。晚于下班时间的会自动预勾加班，随时可以改回来。
5. **填数量 → 点「保存这一笔」**：
   - 数量必须是正整数，填写时下方实时显示「小计 = 数量 × 单价」；
   - 数量超过 5000 件或金额超过 2000 元，会先弹窗确认，防止多按一个 0；
   - 连录时可打开「保存后保留工人 / 保留工序」开关，少点两次。

> **时间精确到分钟**，列表里每条流水前面都会显示时刻（如 `19:20`），同一天的多笔按时间倒序排列。
> 时间只用于记录和排序，**不影响任何金额计算**。

### 加班怎么算钱

加班有两种口径，在「设置 → 加班」里二选一：

| 口径 | 怎么算 | 适合 |
| --- | --- | --- |
| **按倍数乘** | 加班单价 = 正常单价 × 倍率（可选 1.2 / 1.5 / 1.8 / 2.0） | 全厂统一倍率 |
| **按玩具加班单价** | 用「玩具与工序」里每个玩具单独填的加班价 | 不同活工价差别大 |

- 设置里还能定「正常下班时间」（默认 18:00），晚于它录入的流水会自动预勾加班；
- 只是预勾，**随时能手动改**——晚上补录白天干的活不会被硬判成加班；
- 选「按玩具加班单价」但某个玩具没填加班价时，会自动按倍率兜底，**不会算成白干**；
- 结算明细里加班单独成行，标 `加班 ×1.5`，与正常班的同价流水**不会被合并**。

### 单价临时不一样怎么办？

点数量卡片下方的「改单价」，手动填这一次的单价（只影响这一笔，档案单价不动）。
补记过去日期时，也可以手动填当时的单价。

### 记错了怎么改？

- **改**：点这条流水 → 改数量 / 单价 / 日期 / **时间** / **是否加班** / 备注。
  - 只改数量时，仍按**原来的单价快照**重算，不会跟着档案新单价走；
  - 只改备注，金额完全不动；
  - 换工序会提示新单价，确认后才改。
- **删**：长按这条流水 → 确认删除。删除的记录进回收站，**30 天内可恢复**。

### 补贴 / 计时 / 扣款 / 预支

计数页中间有一块 **「补贴 / 计时 / 扣款 / 预支」**，四个按钮各对应一项，点哪个就记哪种。结算页右上角的卡片图标也能直接记，不用先点进某个工人。

| 类型 | 填什么 | 怎么影响工资 |
| --- | --- | --- |
| **补贴** | 补贴名称（如全勤奖、质量奖）+ 金额 | **加到**应付里 |
| **计时** | 工时 × 时薪，或直接填金额 | **加到**应付里 |
| **扣款** | 扣款原因（如次品赔偿）+ 金额 | 从应付里**扣掉** |
| **预支** | 用途（如预支生活费）+ 金额 | 从应付里**扣掉** |

几条规则：

- **金额一律填正数**，加减由「类型」决定，不用自己输负号；
- 名称 / 原因**必填**，月底对账全靠它；
- 日期和时间都能改，补记昨天的补贴不会跑到今天；
- 记完会**立刻显示在计数页的这块列表里**（带时刻和金额），点一下就能改，右侧垃圾桶删除，30 天内可在回收站恢复；
- 这块右上角显示当天调整项的**合计**（如 `合计 -50.00`）。

**计时工资怎么填：**

- 默认 **「按工时 × 时薪」**：填工时（可带小数，如 `3.5`）和时薪（如 `25`），金额自动算出来并显示在下面的预览条里；
- 也可以切到 **「直接填金额」**：比如修机器半天，双方谈好 200 元，直接填 200 就行；
- **工时和时薪必须一起填**，只填一个会提示「工时和时薪要一起填」——防止算成 0 元白干；
- 单笔工时有 24 小时上限，时薪有 1000 元上限，多按一个 0 会被拦下；
- 结算、工资条、CSV 里都会带上工时明细（如 `3.5 小时 × 25.00 元/时`）。

> 某一项这个月一笔都没有，结算里就显示 `0.00`；点进工人详情会写「本期没有补贴 / 计时 / 扣款 / 预支」，不会只有个空框架。

## 四、结算与发工资

`结算` 页：

1. **选区间**：今日 / 近7天 / 本月 / 上月 / 自定义（自定义含首尾两天）。
2. **看合计**：顶部「应付合计」是这段时间要发出去的钱，下面按人排序。
3. **点某个人**：看他的计件明细（同一工序不同单价会分行）、调整项、以及完整公式：

```
本期应付 = 计件工资 + 补贴 + 计时 − 扣款 − 预支
```

- 只有调整项、没有计件的人也会出现在清单里（不会漏发补贴）；
- 应付出现**负数**时会标红并提示「负数，请核对」，通常是预支或扣款录多了。

### 月度锁账（发完工资就锁）

结算页下方的「月度锁账」点一下即可锁住当月：

- 锁账后：该月的流水**不能新增、修改、删除，回收站也不能恢复**；
- 仍然可以：查看、导出 CSV、生成工资条、备份；
- 要改必须先在结算页点同一个按钮**解锁**（会二次确认）。

> 跨月改日期时，系统会同时检查「原月份」和「新月份」，任一月锁账就拒绝。

## 五、发工资条、导表格

### 单人工资条（长图）

`结算 → 点某个工人 → 生成工资条图片`

- 预览可双指放大；明细太长会**自动拆成多张图**，左右滑动查看；
- 「存到相册」保存到手机相册；
- 「发给工人」调起微信 / QQ 直接发。

### 导 Excel 表（CSV）

- 结算表：`结算页右上角 ⬇ 图标` → 存到手机 或 发送给他人；
- 年度报表：`设置 → 年度报表`（或结算页右上角柱状图图标）；
- 文件带 UTF-8 BOM，**Excel / WPS 双击打开不会乱码**。

## 六、备份（强烈建议每周一次）

### 本地备份

`设置 → 导出本地备份` → 选「按默认导出」→ 存到手机任意目录或直接发到微信收藏。

- 默认不包含「删除超过 30 天」的记录，需要完整留档时选「包含超期删除项」；
- 文件名自带版本与时间戳，如 `玩具厂计件备份-v1-20260601-183000.json`。

### 从备份恢复

`设置 → 从备份恢复 → 选文件`，系统会：

1. 先校验文件格式（**损坏文件会被拒绝，原账本一根毫毛都不动**）；
2. 预览：备份时间、流水范围、工人/玩具/流水/调整数量；
3. 二次确认后，**先把当前账本自动备份一份**，再整体覆盖。

### 云端备份（坚果云）

`设置 → 云端备份`：

1. 地址默认填好 `https://dav.jianguoyun.com/dav/`；
2. 账号填坚果云登录邮箱；
3. **应用密码**：坚果云网页版 `账户信息 → 安全选项 → 添加应用` 生成，
   **不是你的登录密码**；
4. 点「保存并测试连接」，成功即可。

用法：

- 打开「自动备份」开关后，**每次打开应用或切回前台**会检查一次：
  距上次成功超过 24 小时、且本地有新数据才上传（不用后台定时器，省电也不会被系统杀掉）；
- 「立即备份」随时手动传一份，**手动备份永不自动删除**；
- 云端只保留最近 **30 份自动备份**，超出自动清理最旧的；
- 「从云端恢复」列出云端文件，选中后走与本地恢复完全一样的校验与预览流程。

> 断网、网盘欠费都不影响记账；失败原因会显示在「备份状态」里。

## 七、字号（看不清就调大）

「设置 → 显示与字号」有三档：**标准 / 大 / 超大**（对应 1.0 / 1.3 / 1.6 倍）。
点一下立刻生效，不用重启，也不用改手机系统字号。

- 三档都是在手机系统字号的基础上再放大，所以系统已经调大的话会更明显；
- 每个页面都会重排，不会出现「字大了但按钮被挤出屏幕」；
- 出厂默认是「标准」；车间光线差、看数字吃力时，建议直接用「大」。

## 九、常见问题

**Q：数字按错了，小数能用逗号吗？**
可以，系统会把全角数字、中文逗号句号自动转成半角。

**Q：为什么两个人同名？**
允许重名（车间常见），列表里靠编号区分；搜索时可以输编号。

**Q：金额会不会算错一分钱？**
不会。单价按「万分之一元」的整数存，每笔小计先四舍五入到分再累加，
结算页脚注明「逐笔取整后合计」。绝不使用平均单价。

**Q：数据存在哪里？会被上传吗？**
全部存在手机本地数据库，只有你自己点「云端备份」才会传到自己的网盘。
云盘账号与应用密码保存在系统安全存储里，不写进账本文件。

**Q：手机丢了怎么办？**
在新手机装同款 APK → `设置 → 云端备份` 填同一个坚果云账号 →
「从云端恢复」选最近一份即可。

**Q：能装到两台手机上吗？**
可以，但两台手机的数据**互不同步**（本版本定位是单机单管理员）。
需要两边都有账，请在各自手机上分别恢复同一份备份，之后只在一台上记账。

## 十、升级注意事项

- 新版本 APK 直接覆盖安装即可，**账本数据不会丢**（同一个签名证书才能覆盖安装）；
- 升级前建议手动做一次本地备份；
- 千万不要卸载重装（卸载会清空应用数据），除非你已经确认备份可用。

# 玩具厂计件计数与工资结算 · 操作手册

> 适用版本：v1.0.0（Android 单机版）
> 使用者：车间统计员 / 老板娘 / 厂长，一台手机一个人用
> 一句话：**装到手机上就能用，不联网也能记账、算钱、发工资条。**

---

## 一、安装

1. 把 `app-release.apk` 传到手机（微信文件传输助手、数据线、U 盘都行）。
2. 点开文件安装。若提示「未知来源应用」，在弹窗里选「允许」或到
   `设置 → 应用 → 特殊权限 → 安装未知应用` 里放行一次。
3. 桌面出现「玩具厂计件」图标，点开即可用。

> 换手机、恢复出厂、误删重装之前，**务必先做一次备份**（见第六节）。

---

## 二、第一次使用（约 10 分钟）

按「设置 → 档案管理」的顺序建好两本底档，之后录计数就只用点选了。

### 1. 建工人档案

`设置 → 工人档案 → 右上角「新增」`

| 字段 | 说明 |
| --- | --- |
| 姓名 | 允许重名，靠编号区分（张三 W001 / 张三 W002） |
| 编号 | 自动生成 W001、W002…，可改成厂里现有工号，**建好后不能改** |
| 电话号码 | **选填**，方便联系；座机带区号、中间加空格都能存 |
| 身份证号 | **选填**，只存在本机，用于建档与核对，不参与工资计算；档案页默认遮住中间位，点眼睛看全 |
| 拼音首字母 | 自动生成，用来快速搜人；多音姓氏（单/曾/解/查/仇/区…）可手动改 |

> 电话 / 身份证号填得**不太像**时（位数不对、校验位对不上），下方会出现一行橙色提醒，
> 但**不会拦住保存**——老档案、手抄错的号码照样能存，确认无误直接点保存即可。
> 两项都可以留空，老账升级后显示「未填写」，不影响任何统计。

### 2. 建玩具与工序

`设置 → 玩具与工序 → 右上角「新增」`

| 字段 | 说明 |
| --- | --- |
| 玩具名 | 例如「小熊」 |
| 工序 | **点一下从列表里选**，不用手打；默认「整件」 |
| 单价 | 单位「元」，**最多 4 位小数**，如 0.035 |

**工序怎么选：**

- 点「工序」会弹出选择列表，预置了 15 个常用工序（整件 / 裁剪 / 缝头 / 缝纫 / 充棉 / 封口 / 手工缝合 / 装配 / 装眼 / 绣花 / 印花 / 剪线 / 整烫 / 包装 / 质检）；
- 列表里没有合适的，点顶部 **「新增工序」**，打字保存后**立刻选中**，而且以后都留在列表里，不用再打一遍；
- 自定义工序右侧有删除按钮。**已经被玩具档案用着的工序删不掉**（会提示），预置工序也不能删——避免历史流水里的工序名突然没有来源；
- 同一玩具不同工序请**分开建**（小熊·整件 / 小熊·充棉）。

> 单价改过之后，**历史流水不会变**：系统在记账时就把当时的单价存下来了。
> 同一工序中途调价，结算时会自动拆成两行分别显示。

## 三、每天记账（最常用）

打开「计数」页，从上到下四步：

1. **核对日期和时间**：**每次进入计数页，日期都会自动回到今天**（上次补录留下的旧日期不会带过来），时间默认当前时刻。补记昨天下午的活，点「改日期」选昨天，再点「改时间」选几点做完的。
2. **选工人**：点「工人」卡片，可按姓名、拼音首字母（如 `zs`）、编号搜索。
3. **选玩具 / 工序**：点「玩具 / 工序」卡片，单价会自动带出来。
4. **确定是不是加班**：卡片里的「正常班 / 加班」开关。晚于下班时间的会自动预勾加班，随时可以改回来。
5. **填数量 → 点「保存这一笔」**：
   - 数量必须是正整数，填写时下方实时显示「小计 = 数量 × 单价」；
   - 下面的 **「这一笔：未结算 / 已结算」** 开关默认关闭（未结算）；
     如果这一笔当场就把钱给了，打开它，保存后直接算已结算，不用再回结算页勾；
   - 数量超过 5000 件或金额超过 2000 元，会先弹窗确认，防止多按一个 0；
   - 连录时可打开「保存后保留工人 / 保留工序」开关，少点两次。

> **时间精确到分钟**，列表里每条流水前面都会显示时刻（如 `19:20`），同一天的多笔按时间倒序排列。
> 时间只用于记录和排序，**不影响任何金额计算**。

### 流水多了怎么翻（查找 + 每页条数）

一天记到几十上百笔时，不用一直往下滑：

- **查找**：流水卡片顶部有查找框，输**姓名**、**工号**或**拼音首字母**都行
  （如「张」「W012」「zs」），标题右侧立刻变成 `匹配 4/120 笔`，
  下面还有一条「按「张」匹配到 4 笔（共 120 笔）」；点输入框右边的 ⊗ 或「清空」恢复全部。
  一笔都匹配不上时会写「没有匹配的流水」，并给 **清空查找** 按钮，不会留一片空白。
- 流水存的是姓名快照，按工号查时系统会拿档案里的工号对照，
  所以**停用过的工人**、**改名之前的旧账**也照样查得到。
- **每页条数**：流水超过 10 笔，卡片底部出现 **每页 10 / 20 / 50** 三个档位，
  点一下立刻生效；旁边是 **上一页 / 第 x/y 页 / 下一页**。
  换档位、改查找词、换日期都会**自动回到第 1 页**，不会翻到空页上。
- 一页只画这一页的行，200 笔也不会一口气铺满屏幕，滑动明显轻。
- 查找和分页**只影响「看哪几条」**：上面的今日合计、小计、结算汇总始终按**全部流水**算，
  不会因为筛掉几个人就少算钱。

> 结算页「按工人结算」也有同样的查找框，输姓名 / 工号定位，200 人不用手滑；
> 两处查找的手感完全一致。

### 加班怎么算钱

加班有两种口径，在「设置 → 加班」里二选一：

| 口径 | 怎么算 | 适合 |
| --- | --- | --- |
| **按倍数乘** | 加班单价 = 正常单价 × 倍率（可选 1.2 / 1.5 / 1.8 / 2.0） | 全厂统一倍率 |
| **按玩具加班单价** | 用「玩具与工序」里每个玩具单独填的加班价 | 不同活工价差别大 |

- 设置里还能定「正常下班时间」（默认 18:00），晚于它录入的流水会自动预勾加班；
- 只是预勾，**随时能手动改**——晚上补录白天干的活不会被硬判成加班；
- 选「按玩具加班单价」但某个玩具没填加班价时，会自动按倍率兜底，**不会算成白干**；
- 结算明细里加班单独成行，标 `加班 ×1.5`，与正常班的同价流水**不会被合并**。

### 单价临时不一样怎么办？（临时调价 / 永久改价）

这是两个**完全不同**的动作，别搞混：

| 想做的事 | 去哪 | 影响范围 |
| --- | --- | --- |
| 这一笔价格特殊（返工、老货、临时议价） | 计数页 → 数量卡片右上角 **「临时调价」** | **只有这一笔**，档案不动 |
| 以后所有新录入都按新价 | **设置 → 玩具工序** → 改「单价」 | 以后新录入；已产生的流水不变 |

点「临时调价」后：

- 输入框会带出**当前档案价**，改成这次的价即可，小计实时跟着变；
- 卡片下方会有紫色提示：**「只对这一笔生效，档案单价不会被改动」**；
- 单价与档案不一致时，流水统计和详细明细那一行会自动出现紫色 **「临时调价」** 角标；
- 想退回按档案价算，点 **「用档案价」** 即可。

> 计数页里**没有**任何入口能改档案价——想永久改价必须去「设置 → 玩具工序」，
> 就是为了防止"随手改一下"把全厂工价改掉。
>
> 单价一律按纯数字显示（如 `0.20`），不会出现「本次单价 0.20 元」这种重复单位的写法；
> 金额（小计、应付）才带「元」。

### 补录：今天录、账记到前面的日期

补记前几天的活是常事，但一定要分清两个时间：

| 时间 | 意思 | 谁在用 |
| --- | --- | --- |
| **归属日期 / 业务时刻** | 这活是哪天、几点干的 | 日汇总、结算、工资条、CSV **全按它算** |
| **录入时间** | 你什么时候按的保存键（精确到秒） | 只用于查账，**不参与任何计算** |

举例：今天 22 号，把 11 号的活补进去 ——

- 这笔账**算在 11 号**，日汇总和结算都归 11 号，22 号的「今日笔数」不会多出来；
- 明细里这一行会标红并带 **「补录 11 天」** 角标，一眼能看出是今天补的；
- 点这一行会弹出时间详情：**归属日期、业务时刻、录入时间（`2026-11-22 16:32:41`）** 并排列出，当面核对不会各说各话。

补录过程中顶部会一直显示红色提示条「正在补录 2026-11-11（今天 2026-11-22）」，
记完点 **「回今天」** 或切到别的页再回来，日期就会回到今天。

> 从结算页或工人详情里补录 **补贴 / 扣款** 时，默认日期会跟着**当前看的区间**走
> （看 10 月就默认 10 月 31 日），不会记到今天去——否则钱就跑到下个月，当期看不见。

### 记错了怎么改？

- **改**：点这条流水 → 改数量 / 单价 / 日期 / **时间** / **是否加班** / 备注。
  - 只改数量时，仍按**原来的单价快照**重算，不会跟着档案新单价走；
  - 只改备注，金额完全不动；
  - 换工序会提示新单价，确认后才改。
- **删**：长按这条流水 → 确认删除。删除的记录进回收站，**30 天内可恢复**。

### 补贴 / 计时 / 扣款 / 预支

计数页中间有一块 **「补贴 / 计时 / 扣款 / 预支」**，四个按钮各对应一项，点哪个就记哪种。结算页右上角的卡片图标也能直接记，不用先点进某个工人。

| 类型 | 填什么 | 怎么影响工资 |
| --- | --- | --- |
| **补贴** | 补贴名称（如全勤奖、质量奖）+ 金额 | **加到**应付里 |
| **计时** | 工时 × 时薪，或直接填金额 | **加到**应付里 |
| **扣款** | 扣款原因（如次品赔偿）+ 金额 | 从应付里**扣掉** |
| **预支** | 用途（如预支生活费）+ 金额 | 从应付里**扣掉** |

几条规则：

- **金额一律填正数**，加减由「类型」决定，不用自己输负号；
- 名称 / 原因**必填**，月底对账全靠它；
- 日期和时间都能改，补记昨天的补贴不会跑到今天；
- 记完会**立刻显示在计数页的这块列表里**（带时刻和金额），点一下就能改，右侧垃圾桶删除，30 天内可在回收站恢复；
- 这块右上角显示当天调整项的**合计**（如 `合计 -50.00`）。

**计时工资怎么填：**

- 默认 **「按工时 × 时薪」**：填工时（可带小数，如 `3.5`）和时薪（如 `25`），金额自动算出来并显示在下面的预览条里；
- 也可以切到 **「直接填金额」**：比如修机器半天，双方谈好 200 元，直接填 200 就行；
- **工时和时薪必须一起填**，只填一个会提示「工时和时薪要一起填」——防止算成 0 元白干；
- 单笔工时有 24 小时上限，时薪有 1000 元上限，多按一个 0 会被拦下；
- 结算、工资条、CSV 里都会带上工时明细（如 `3.5 小时 × 25.00 元/时`）。

> 某一项这个月一笔都没有，结算里就显示 `0.00`；点进工人详情会写「本期没有补贴 / 计时 / 扣款 / 预支」，不会只有个空框架。

## 四、结算与发工资

`结算` 页：

1. **选区间**：点最上方的区间卡片（写着「切换区间」），弹出完整列表，按周期分组，每项都标了起止日期：

| 分组 | 可选 | 口径 |
| --- | --- | --- |
| 周 | 本周 / 上周 | 周一到周日 |
| 月 | 这个月 / 上个月 | 自然月 |
| 季度 | 这个季度 / 上个季度 | 自然季度 Q1（1–3）/ Q2（4–6）/ Q3（7–9）/ Q4（10–12） |
| 半年 | 这半年 / 上半年 | 「这半年」= **当前所在**的 1–6 月或 7–12 月；「上半年」= 当年 1–6 月 |
| 年 | 这一年 / 上一年 | 自然年 1 月 1 日–12 月 31 日 |

   - 选中立刻生效，合计、工人列表、锁账月份一起刷新；
   - 列表最下方 **「自定义区间」** 可以自己选起止日期（含首尾两天），选完区间卡片会显示「自定义区间」；
   - 下半年时「这半年」是 7–12 月，和「上半年」不同；上半年时两者相同，列表里会直接写出来，不用猜。
2. **看合计**：顶部「应付合计」是这段时间要发出去的钱，下面按人排序。
3. **看结算进度**：汇总卡下方分「未结算 / 已结算」两块，金额与人数分开算，
   一眼看出还有多少钱没发。
4. **排序 / 筛选（一个按钮）**：查找框右边那个按钮（写着当前口径，如 `金额↓ · 全部`），
   点开一个面板，里面全齐：
   - **按人名**（拼音首字母 + 姓名）、**按工号**（数值感知：`A2` 排在 `A10` 前、
     `002` 排在 `010` 前）、**按金额 / 总付**（可切 `从高到低 ↓` / `从低到高 ↑`）；
   - **全部 / 已结 / 未结**：选「已结 / 未结」是**筛选**，列表只留对应状态的人；
   - **恢复默认**回到「按金额从高到低 + 全部」。
   选中立刻生效，不用先关面板。
   > 三者叠加不打架：先按状态筛出人，再用查找词定位，最后只**改顺序**；
   > 顶部「应付合计」永远按全员算，不会因为筛掉几个人就少算钱。
5. **找人**：查找框输**姓名**、**工号**或**拼音首字母**都行
   （如「张」「W012」「zs」），右边显示「匹配 3/200 人」，点 ⊗ 或「清空」恢复全部；
   面板里选的状态和排序对查找结果同样生效。
6. **点某个人**：看他的计件明细（同一工序不同单价会分行）、调整项、以及完整公式：

```
本期应付 = 计件工资 + 补贴 + 计时 − 扣款 − 预支
```

- 只有调整项、没有计件的人也会出现在清单里（不会漏发补贴）；
- 应付出现**负数**时会标红并提示「负数，请核对」，通常是预支或扣款录多了。

### 汇总卡可以折叠，也可以点开看全员

人多、区间长（比如看一整年）时，先把页面缩短再干活：

- 点「应付合计」右上角 **收起明细**：只留三个核心数字——**合计（含人数）**、
  **已结算（金额 + 人数）**、**未结算（金额 + 人数）**，计件/补贴/计时/扣款/预支与笔数先收起来；
  再点 **展开明细** 恢复原样。折叠只影响显示，金额口径完全不变。
- 「月度锁账」超过 6 个月（半年 / 全年）时**默认收起**，只报
  **已锁 X 个月 / 未锁 Y 个月**；点 **展开 N 个月** 才显示逐月圆片，锁 / 解锁照常可用。

### 从汇总项直接看全员、直接结账（v1.6）

这是和「按工人结算」并列的第二种视角，专门解决"月底还有谁没发钱"：

| 点什么 | 看到什么 | 能做什么 |
| --- | --- | --- |
| **未结算** | 还欠钱的全员名单（含部分已结），各人未结金额与笔数 | 每行右侧 **结清本期** 直接标记；点人名进完整账单 |
| **已结算** | 已经结清的全员名单 | 每行右侧 **取消结算** 退回未结 |
| **计件 / 补贴 / 计时 / 扣款 / 预支** | 有这一项的全员名单，按金额从大到小排 | 点人展开看逐笔；单笔 **结算 / 取消**；**全部结清** 只结这一项；**完整明细** 跳该人账单 |

- **两种视角的分工**：「按工人结算」= 从人找账（看某一个人的完整账单）；
  点汇总项 = 从维度找人（按"未结算 / 扣款"横向筛出涉及的人）。
- 名单里都能再输姓名 / 工号查找，200 人也不用手滑。
- 下钻里的每个操作都**立刻生效**：弹层里的合计与背后页面的汇总卡会同时刷新，
  关掉弹层不用再手动下拉刷新。
- 下钻里点 **补录一笔扣款** 时，默认日期落在**当前结算区间内**，
  不会跑到下个月去（这是对账最常踩的坑）。

### 结算状态：可以整期标，也可以逐笔标

两层并存，按需选一种：

**① 整期一次标（发完整个月时最快）**

1. 点工人进详情，动作区有 **「标记本期已结算」**（跨月的区间会一次标完所有有账的月份）；
2. 标完后该工人显示绿色 **已结算**，筛「未结算」就不再出现；
3. 标错了点 **「取消已结算」** 退回，**金额一分不动**。

**② 逐笔标（先结一部分、或者某笔有争议时）**

1. 进 **「详细明细」**，每一行右侧都有小按钮：未结显示 **「结算」**，已结显示 **「取消」**；
2. 点一下立刻生效，顶部「已结 / 未结」两块金额与笔数同步刷新；
3. 明细里新增 / 修改时，也能直接在表单里选 **已结算**，保存即入账。

状态判定按**笔数**：

| 显示 | 含义 |
| --- | --- |
| 未结算 | 一笔都还没标 |
| 部分已结 | 结了一部分（金额按实际已结的那几笔算） |
| 已结算 | 这个区间里每一笔都标了 |

> **已结算 + 未结算 永远等于应付**，逐笔结到什么程度都不会对不上账。
>
> **结算状态 ≠ 锁账**：锁账管「能不能改账」，结算状态管「钱发没发」。
> 可以先标已结算再锁账，也可以先锁账再回头标——两者互不干扰，
> 已锁账的月份照样能勾逐笔结算。
>
> 整期标记之后又补录了新账，新账是**未结算**的，这个人的状态会立刻退回「部分已结」——
> 这正是我们想要的提醒：钱又变了，得再核一次。
>
> 在整期已标的月份里取消某一笔时，系统会把这个月拆成逐笔标记（其余仍为已结算），
> 取消完不会"刷新一下又变回已结算"。

### 结算状态变更历史（v1.7）

每次「标记已结算」或「取消已结算」都会**追加**一条变更记录，不是覆盖旧时间：

- **取消理由选填**：点「取消已结算」会弹一个输入框，可以直接输，
  也可以点现成的常用理由（算错金额重结 / 工人有异议 / 补录后重算 / 重复标记）；
  **留空也能正常完成取消**，不强制填写。
- **时间戳不覆盖**：每条记录都有精确到秒的时间（`2026-11-22 10:15:30`）和
  一个追加标识 `#1 / #2 / #3 …`。后来再结算、再取消只会往后加，
  前面所有记录的时间与理由原样保留。
- **当前状态标识**：工人详情顶部写着「当前状态：已结算 / 部分已结 / 未结算」、
  「共 N 次变更 · 最近 #x 于 …」，旁边点 **「变更历史」** 看完整列表
  （动作、时间、涉及月份 / 区间、取消理由，按时间倒序）。
- **录入时直接勾「这一笔：已结算」、在明细里逐笔结算 / 取消**，同样会追加历史；
  逐笔取消不弹理由框，保持一点即生效，理由记为空。
- **打印 / 导出总表不含这些**：CSV 总表只有 12 列正式汇总字段，
  时间戳、取消理由、变更历史**只在详情与历史面板里看**，
  工资条和年度报表也不会带上，免得给工人看的单子上出现一堆审计字样。

### 详细明细（逐条对账）

工人详情里点 **「详细明细」**：

- 按**当前选区间的每一笔**列出来，不再合并：日期（带星期）、时刻、玩具 / 工序、
  数量 × 单价、金额、备注；
- 每一行都带 **已结算 / 未结算** 小标签，右侧还有 **「结算 / 取消」** 按钮，可以逐笔改状态；
- 单价与档案不同时带紫色 **「临时调价」** 角标（档案本身没被改）；
- 补贴 / 计时 / 扣款 / 预支也混在时间线里，按天汇总「当日合计」；
- 顶部可按 **全部 / 未结算 / 已结算** 筛选，发工资时当面对账很快；
- 日期标题后面带**假期角标**：`国庆节 · 休` = 法定放假，`调休上班` = 周末补班（两者颜色不同）；
- **今天补录的旧账会标红**：左侧红竖条 + 浅红底 + 「补录 N 天」角标，组长扫一眼就知道哪几笔是刚补的；
- 顶部还会写「本区间有 N 笔是今天补录的」；
- **点任意一条**都会弹出时间详情：归属日期（哪天的活）、业务时刻、**录入时间（精确到秒）**，
  补录的那笔还会注明「账算在 11-11，统计不会算到今天」。

### 月度锁账（发完工资就锁）

结算页下方的「月度锁账」点一下即可锁住当月：

- 锁账后：该月的流水**不能新增、修改、删除，回收站也不能恢复**；
- 仍然可以：查看、导出 CSV、生成工资条、备份；
- 要改必须先在结算页点同一个按钮**解锁**（会二次确认）。

> 跨月改日期时，系统会同时检查「原月份」和「新月份」，任一月锁账就拒绝。

## 六、备份（强烈建议每周一次）

### 本地备份

`设置 → 导出本地备份` → 选「按默认导出」→ 存到手机任意目录或直接发到微信收藏。

- 默认不包含「删除超过 30 天」的记录，需要完整留档时选「包含超期删除项」；
- 文件名自带版本与时间戳，如 `玩具厂计件备份-v1-20260601-183000.json`。

### 从备份恢复

`设置 → 从备份恢复 → 选文件`，系统会：

1. 先校验文件格式（**损坏文件会被拒绝，原账本一根毫毛都不动**）；
2. 预览：备份时间、流水范围、工人/玩具/流水/调整数量；
3. 二次确认后，**先把当前账本自动备份一份**，再整体覆盖。

### 云端备份（坚果云）

`设置 → 云端备份`：

1. 地址默认填好 `https://dav.jianguoyun.com/dav/`；
2. 账号填坚果云登录邮箱；
3. **应用密码**：坚果云网页版 `账户信息 → 安全选项 → 添加应用` 生成，
   **不是你的登录密码**；
4. 点「保存并测试连接」，成功即可。

用法：

- 打开「自动备份」开关后，**每次打开应用或切回前台**会检查一次：
  距上次成功超过 24 小时、且本地有新数据才上传（不用后台定时器，省电也不会被系统杀掉）；
- 「立即备份」随时手动传一份，**手动备份永不自动删除**；
- 云端只保留最近 **30 份自动备份**，超出自动清理最旧的；
- 「从云端恢复」列出云端文件，选中后走与本地恢复完全一样的校验与预览流程。

> 断网、网盘欠费都不影响记账；失败原因会显示在「备份状态」里。

## 七、字号（看不清就调大）

「设置 → 显示与字号」有三档：**标准 / 大 / 超大**（对应 1.0 / 1.3 / 1.6 倍）。
点一下立刻生效，不用重启，也不用改手机系统字号。

- 三档都是在手机系统字号的基础上再放大，所以系统已经调大的话会更明显；
- 每个页面都会重排，不会出现「字大了但按钮被挤出屏幕」；
- 出厂默认是「标准」；车间光线差、看数字吃力时，建议直接用「大」。

## 九、常见问题

**Q：数字按错了，小数能用逗号吗？**
可以，系统会把全角数字、中文逗号句号自动转成半角。

**Q：为什么两个人同名？**
允许重名（车间常见），列表里靠编号区分；搜索时可以输编号。

**Q：金额会不会算错一分钱？**
不会。单价按「万分之一元」的整数存，每笔小计先四舍五入到分再累加，
结算页脚注明「逐笔取整后合计」。绝不使用平均单价。

**Q：数据存在哪里？会被上传吗？**
全部存在手机本地数据库，只有你自己点「云端备份」才会传到自己的网盘。
云盘账号与应用密码保存在系统安全存储里，不写进账本文件。

**Q：我今天补了 11 号的活，为什么「今天笔数」没变？**
因为它算的是 11 号。系统只按「归属日期」统计，不按「哪天录的」统计——
这才能保证月底对账和实际干活的日子对得上。去 11 号的明细里能看到这笔，并带红色「补录」标记。

**Q：明细里红色的「补录 11 天」是什么意思？**
表示这一笔是**今天**录进去的，但账算在 11 天前。红色只是提醒，不影响金额；
点这一行能看到精确到秒的录入时间，方便核对「到底什么时候补的」。

**Q：我在计数页改了单价，会不会把档案价也改了？**
不会。计数页的「临时调价」只写这一笔的单价，档案价一分不动；
想永久改价请到「设置 → 玩具工序」。那一笔在列表里会带紫色「临时调价」角标，
提醒你别拿它跟当前档案价比。

**Q：能不能只结其中几笔？**
可以。进工人详情的「详细明细」，每行右侧点「结算」就只结那一笔；
顶部的已结 / 未结金额和笔数会立刻跟着变。想整期一次结完，还是用「标记本期已结算」。

**Q：日历上的「休」「班」会不会影响工资？**
不会。它们只是日期提示（`休`=法定放假、`班`=调休补班），计件、加班、结算的算法完全没有变。

**Q：一天两百笔流水，找某个人的那一笔要滑很久吧？**
不用。流水卡片顶部直接输姓名 / 工号 / 拼音首字母，匹配数和总数一起报；
底部还能切「每页 10 / 20 / 50」翻页。换查找词或档位会自动回到第 1 页，
查找只筛显示，不影响上面的合计金额。结算页「按工人结算」也有同一个查找框。

**Q：把「应付合计」收起来，数字会不会跟着变少？**
不会。折叠只是把计件 / 补贴 / 计时 / 扣款 / 预支与笔数明细藏起来，
**合计（含人数）、已结算（金额 + 人数）、未结算（金额 + 人数）** 三个核心口径一直留着，
「已结 + 未结 = 应付」照旧成立；「月度锁账」折叠后也仍报「已锁 X 个月 / 未锁 Y 个月」。
展开就恢复完整明细，锁账、结算操作都不受影响。

**Q：「点未结算看全员」和「按工人结算」有什么区别？**
「按工人结算」是**从人找账**：点一个人，看他这一期的完整账单；
点汇总项（未结算 / 已结算 / 扣款 / 补贴…）是**从维度找人**：
一次把所有还欠钱的人、或者有扣款的人筛出来，直接在名单里结清 / 取消 / 看逐笔。
两个视角用的是同一套结算动作，操作完背后汇总卡与弹层里的数字同时刷新。

**Q：工人列表能按工号或金额排吗？「已结 / 未结」怎么筛？**
都在查找框右边那一个「排序 / 筛选」按钮里：按人名 / 按工号 / 按金额（可切升降序），
以及全部 / 已结 / 未结。工号按数值排，`A2` 在 `A10` 前；
「已结 / 未结」是筛选，排序只改顺序，查找再叠加，三者一起用也不冲突，
顶部合计始终按全员算。

**Q：取消已结算必须填理由吗？历史记录会印到总表上吗？**
理由**选填**，留空也能完成。每次结算 / 取消结算都会追加一条带精确到秒时间的记录
（`#1`、`#2`…），旧时间永远不会被覆盖；在工人详情点「变更历史」能看到完整流水。
这些时间戳、理由和历史**不会**出现在导出的总表、工资条或年度报表里，
只在详情 / 历史面板展示。

**Q：手机丢了怎么办？**
在新手机装同款 APK → `设置 → 云端备份` 填同一个坚果云账号 →
「从云端恢复」选最近一份即可。

**Q：能装到两台手机上吗？**
可以，但两台手机的数据**互不同步**（本版本定位是单机单管理员）。
需要两边都有账，请在各自手机上分别恢复同一份备份，之后只在一台上记账。

## 十、升级注意事项

- 新版本 APK 直接覆盖安装即可，**账本数据不会丢**（同一个签名证书才能覆盖安装）；
- 升级前建议手动做一次本地备份；
- **v1.3 起**：工人档案多了「电话 / 身份证号」（选填），结算多了「已结算 / 未结算」。
  升级后**历史账目一律显示「未结算」**，请按实际情况把已经发过钱的月份点一下「标记本期已结算」；
  这一步不影响金额，只是让筛选和统计分得清。
- **v1.4 起**：结算页的区间改成一个入口 + 完整列表（周 / 月 / 季度 / 半年 / 年），
  计数页每次进入都会把日期重置为今天，明细页会标出「今天补录的旧账」并可查看精确录入时间，
  日期日历上多了法定假期 / 调休上班角标。
  这些**全是展示与操作便利上的改动，历史金额一分不变**；补录记录只是多了个红色标记，归属日期跟以前一样。
- **v1.5 起**：数据库升到 v5，流水与调整项多了「单笔结算」字段。
  升级后历史账目的结算状态与金额**完全不变**（老账沿用它所在月份的整月标记），
  只是多了一种更细的结法；计数页多了「临时调价」入口与「这一笔已结算」开关；
  备份格式升到 v5，v1–v4 的老备份仍可正常恢复。
- **v1.6 起**：**纯交互增强，数据库不动**（仍是 v5，备份格式也不变，老备份照常恢复）。
  流水页与结算页「按工人结算」都加了查找（姓名 / 工号 / 拼音首字母）；
  流水页多了每页 10 / 20 / 50 分页；看半年、全年时「应付合计」「月度锁账」可以折叠；
  点「未结算 / 已结算 / 扣款 / 补贴」等汇总项可按全员视角下钻并直接结算。
  这些只是查找、显示与操作入口的变化，**历史金额与结算状态一分不变**。
- **v1.7 起**：数据库升到 v6，多一张**只追加**的结算状态变更历史表
  （备份格式同步升到 v6，v1–v5 老备份仍可恢复，缺历史表按空处理）。
  升级后**历史金额与结算状态一分不变**，也不会凭空补造升级前的变更记录；
  「按工人结算」改成一个「排序 / 筛选」按钮（人名 / 工号自然序 / 金额升降序 + 已结未结）；
  取消已结算多了选填理由框；详情里可看当前状态标识与完整变更历史；
  打印总表仍只输出正式汇总，不含时间戳与理由。
- 千万不要卸载重装（卸载会清空应用数据），除非你已经确认备份可用。
